# 🏥 Healthcare Data Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on a healthcare dataset using Python. It explores patient demographics, medical conditions, hospital admission types, billing amounts, and insurance providers through data analysis and visualization.

The main objective is to understand patterns and distributions in healthcare data using statistical analysis and graphical representations.

## 📂 Project Files

| File Name | Description |
|---|---|
| `Task6_EDA.ipynb` | Jupyter Notebook containing Python code for exploratory data analysis and visualizations. |
| `healthcare_preprocessed (1).csv` | Preprocessed healthcare dataset used for the analysis. |

## 📊 Dataset Information

- **Total Records:** 54,966
- **Total Columns:** 18
- **File Format:** CSV

### Key Features

- **Patient Information:** Name, Age, Gender, Blood Type
- **Medical Information:** Medical Condition, Medication, Test Results
- **Hospital Information:** Hospital, Doctor, Room Number
- **Admission Details:** Admission Date, Discharge Date, Admission Type, Admission Urgency
- **Financial Information:** Billing Amount, Insurance Provider
- **Additional Features:** Length of Stay, Age Group

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Analysis Performed

### 1. Patient Demographics
- Analyzed the distribution of patient ages.
- Compared age distributions by gender.
- Visualized the number of patients in each gender category.

### 2. Medical Conditions
- Examined the distribution of different medical conditions.
- Compared medical conditions across genders.
- Visualized patient counts for each medical condition.

### 3. Hospital Admissions
- Analyzed admission types, including emergency, urgent, and other recorded categories.
- Examined the relationship between medical conditions and admission types.
- Used stacked bar charts to compare admission patterns.

### 4. Billing Analysis
- Explored the distribution of patient billing amounts.
- Compared billing amount distributions across medical conditions.
- Calculated average billing amounts for different medical conditions.
- Compared billing amount distributions across insurance providers.

## 📈 Visualizations

The notebook uses the following visualization techniques:

- Histograms with KDE curves
- Bar charts
- Count plots
- Stacked bar charts
- Violin plots

These visualizations help identify distributions, compare categories, and explore relationships between healthcare variables.
